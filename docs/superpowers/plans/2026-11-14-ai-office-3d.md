# AI Office 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ganti kantor SVG di Command Center dengan kantor 3D isometrik (grid 2×3 + lorong) yang karakternya bergerak berdasarkan telemetri asli AutoClipper.

**Architecture:** Backend telemetri ditambah pelacakan panggilan yang sedang berjalan (`inflight`), penanda job asal (contextvar), dan `scene_health` 1 jam. Frontend menurunkan "model adegan" murni dari respons `/api/command-center` (`sceneModel.js`, diuji vitest), lalu React Three Fiber merender ruangan, karakter prosedural low-poly, dan inti Otak AI. Panel data lama tetap.

**Tech Stack:** FastAPI + pytest (backend), React 18 + Vite, `three@^0.160`, `@react-three/fiber@^8.17`, `@react-three/drei@^9.114`, `@react-three/postprocessing@^2.16`, vitest (frontend), Playwright untuk tangkapan layar.

**Spec:** `docs/superpowers/specs/2026-11-14-ai-office-3d-design.md` (+ `assets/referensi-agent-hq.png`, `assets/mockup-tata-letak.html`)

## Global Constraints
- Proyek bukan repo git: Task 0 membuat `backup-ai-office-3d-2026-11-14/`. Langkah "commit" diganti **checkpoint** (jalankan semua tes, catat lulus).
- Tata letak tetap: baris atas Unduh & Data (hijau) · Analis Klip (biru) · Studio Horor (oranye); baris bawah Ruang Suara (magenta) · Otak AI (biru tua + cyan, tengah) · Render + Affiliate (teal, area merah Affiliate & Video Jadi).
- Gerak karakter HANYA dari data (`running`, `inflight`, `log`, `scene_health`). Tidak ada gerak acak saat siaga, kecuali di Mode Demo yang berlabel jelas.
- Halaman harus ringan: `frameloop` berhenti saat `document.hidden`, FPS dibatasi 30, bayangan hanya dari 1 lampu arah (shadow map ≤ 1024).
- Aset hanya buatan kode (primitif three.js) atau CC0. Fase ini: **karakter & furnitur prosedural dari primitif**, tanpa unduhan aset _(keputusan Claude: sesuai §9 spec, bebas lisensi, ukuran kecil, gaya mainan seperti referensi; GLB/Blender menyusul)_.
- UI panel mengikuti `DESIGN.md` (grafit gelap, aksen `#FFD100`, Archivo). Warna-warni hanya di dalam adegan 3D. Semua teks UI berbahasa Indonesia.
- Backend wajib di-restart setelah perubahan Python (`backend/run_detached.bat` via WMI). Frontend wajib `npm run build` agar tampil di `127.0.0.1:8000`.

## Review Focus
1. **WebGL tidak tersedia / context lost** → adegan diganti pesan "Tampilan 3D tidak didukung di browser ini" dan panel data tetap jalan. Tes: Task 6 Step 4.
2. **Agent id tidak dikenal** (mode baru, mis. `job:podcast`, `llm:openrouter`) → tetap muncul di ruangan default (`llm:*` → Otak AI, lainnya → Analis Klip), tidak hilang. Tes: Task 3 Step 1 (`unknownAgentGoesToDefaultRoom`).
3. **Banyak panggilan LLM bersamaan** → paling banyak 4 karakter berjalan ke Otak AI sekaligus; sisanya hanya membuat inti berdenyut. Tes: Task 3 Step 1 (`tripsAreCapped`).
4. **Backend tak terjangkau / poll gagal** → adegan mempertahankan keadaan terakhir + lencana "Terputus", tanpa crash. Tes: Task 6 Step 4.
5. **Tab lama tersembunyi lalu dibuka** → event LLM lama (>15 dtk) tidak memicu antrean perjalanan beruntun. Tes: Task 3 Step 1 (`staleEventsIgnored`).
