Kamu membantu tim konten video horor pendek berbahasa Indonesia (format vertikal 9:16 untuk TikTok/Reels/Shorts).

TUGAS (kerjakan berurutan):
1. Cari di web 5 ide/judul video horor yang SEDANG ramai saat ini di Indonesia (TikTok, YouTube Shorts, Reels). Untuk tiap judul catat: judul/tema, platform, alasan ramai, dan URL sumber yang benar-benar kamu buka. Jangan mengarang sumber; kalau pencarian gagal, tulis jelas bahwa itu perkiraan, bukan hasil pencarian.
2. Dari tiap temuan, buat 1 ide konten ORISINAL (bukan menjiplak): judul, hook 3 detik pertama, premis 2-3 kalimat, lokasi, sosok/ancaman, twist akhir, dan estimasi durasi (45-90 detik).
3. Tulis "AI Horror Production Pipeline": langkah produksi per ide yang nanti dikerjakan agent lain (Claude) memakai tool yang SUDAH ADA berikut:
   - LLM menulis naskah narasi sudut pandang "kamu", sekitar 15 adegan
   - gambar per adegan dibuat dengan SDXL (ComfyUI), 2 sudut kamera per adegan, karakter utama konsisten
   - narasi suara TTS bahasa Indonesia (narator pria, tempo pelan)
   - efek parallax 2.5D dari gambar, SFX horor (11 jenis: ketukan, langkah, bisikan, pintu, dll), render MP4 dengan subtitle
   Untuk tiap ide tulis: ringkasan naskah per babak (hook, pembangunan, puncak, twist), gaya visual + contoh prompt gambar bahasa Inggris untuk 3 adegan kunci, titik SFX, dan checklist kualitas.
4. Urutkan 5 ide dari yang paling layak diproduksi dulu, dengan alasan singkat.

ATURAN:
- Simpan seluruh hasil ke SATU file bernama AI-Horror-Production-Pipeline.md di folder kerja saat ini. Jangan membuat, mengubah, atau menghapus file di luar folder ini.
- Jangan menginstal apa pun dan jangan menjalankan perintah selain yang perlu untuk mencari di web dan menulis file itu.
- Tulis dalam bahasa Indonesia. Di akhir, balas dengan ringkasan 5 baris dan sebutkan berapa sumber yang benar-benar berhasil kamu buka.
